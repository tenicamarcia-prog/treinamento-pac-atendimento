# Treinamento PAC no Atendimento

Treinamento interativo sobre os **Três Estados de Ego** (Pai, Adulto e Criança) aplicado ao atendimento ao cliente, baseado na Análise Transacional.

## Conteúdo

- Mapa mental interativo
- Explicações detalhadas dos estados de ego
- Dinâmica de transações (cruzadas e complementares)
- Estratégia de ouro: ativar o Adulto
- Quiz de fixação com 5 perguntas
- Animações CSS modernas

## Como usar

Abra o arquivo `index.html` no navegador ou acesse o deploy no Vercel.
