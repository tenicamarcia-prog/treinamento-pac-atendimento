# Treinamento PAC no Atendimento

Material didático interativo sobre **retenção no primeiro contato** combinado com o método **PAC** (Pai, Adulto e Criança) da Análise Transacional.

## Como usar

Abra o arquivo `index.html` no navegador — é um HTML único e autocontido (imagens embutidas em base64), funciona offline, sem build e sem dependências.

## Conteúdo

| Seção | Descrição |
|---|---|
| Tudo é relevante | Por que a retenção nasce nos detalhes, antes do "cancelar" |
| Método | Os 4 movimentos: Ouvir → Investigar → Resolver → Reter |
| Mapa Mental | Estados de ego clicáveis, com link direto para os cards |
| Explicação dos Estados | Pai Crítico, Pai Protetor, Adulto, Criança (Livre, Rebelde, Submissa) |
| Dinâmica das Transações | Transação Cruzada vs. Complementar, com diálogos comentados |
| Estratégia de ouro | Como ativar o Adulto em cada estado de chegada |
| Benefícios | Inteligência emocional, resolução rápida, fidelização |
| Avaliação | Formulário de feedback via QR Code |

## Recursos técnicos

- Layout responsivo (4 → 2 → 1 colunas)
- Animações CSS puro (pulso nos passos, entradas por scroll via `IntersectionObserver`)
- Nav com scroll-spy e âncoras por seção
- Cards de estado expansíveis e mapa mental interativo
- Sem frameworks, sem build, sem dependências externas

## Stack

HTML5 + CSS3 (custom properties, grid, flexbox) + JavaScript vanilla.
Tipografia: Inter e Space Grotesk (Google Fonts).
